# 番茄钟 · 专注计时

一个单文件网页小应用：专注 25 分钟、短休息 5 分钟、长休息 15 分钟三种模式，带环形进度条、开始/暂停/重置和今日完成计数，计时结束有提示音。

## 预览

```bash
python3 -m http.server 8000
```

然后打开 http://127.0.0.1:8000/ 即可使用，无需构建、无任何依赖。

## 功能

- 三种模式一键切换：专注 25 分钟 / 短休息 5 分钟 / 长休息 15 分钟
- 环形进度条实时显示剩余时间占比
- 开始 / 暂停 / 继续 / 重置
- 计时结束提示音，专注完成后自动计入今日番茄数
- 纯静态单文件，双击 `index.html` 也能直接打开使用
